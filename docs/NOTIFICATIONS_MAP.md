## 4. EXPIRED — Подписка истекла или отменена

### Сразу при истечении подписки по дате
Триггер: Scheduler (ежедневно в 09:00 Madrid), `subscription_end_date < today`

```

Автоматическое списание не прошло или было отменено. Доступ к каналу клуба и боту GregoChat приостановлен.

Чтобы вернуться к занятиям, оплатите продление.

👉 Оплатить: /pay
```

### Сразу при отмене подписки в Stripe
Триггер: Webhook `customer.subscription.deleted`

```
Подписка отменена

Вы отключили автопродление. Доступ к материалам клуба и боту закрыт.

Мы храним ваш профиль. Если решите вернуться — просто оформите новую подписку.

👉 Вернуться: /pay
```

Триггер: Webhook `invoice.payment_failed`

```

— Недостаточно средств на карте
— Карта заблокирована или истёк срок

Пожалуйста, обновите способ оплаты, чтобы сохранить доступ.

👉 /status
```

## 5. RSVP События — Созвоны с записью

### Напоминание о записи за 24 часа до события
Триггер: Scheduler (каждую минуту), `rsvp_event_datetime` попадает в окно около `now + 24h`, `reminder_24h_sent = False`

Отправляется только пользователям без RSVP-ответа.

```
📅 Запись на завтрашний спикинг

Завтра пройдет встреча на тему:
{event_title}

📆 {event_date}
⏰ {event_time}
```

### Напоминание участникам за 15 минут
Триггер: Scheduler (каждую минуту), `rsvp_event_datetime ~= now + 15min`, `reminder_15min_sent = False`

### Напоминание участникам за 5 минут
Триггер: Scheduler (каждую минуту), `rsvp_event_datetime ~= now + 5min`, `reminder_5min_sent = False`

## ⚠️ Известная проблема

При перезапуске бота или если пользователь зарегистрировался давно — **все шаги напоминаний отправляются разом** за один проход scheduler, потому что все временные условия уже выполнены. Нужно добавить защиту: не отправлять следующий шаг в том же проходе.
