# Tilda legal documents site

## Файлы

- `index.html` — полноценная статическая страница с юридическими материалами
- `styles.css` — стили для локального сайта
- `tilda_embed.html` — готовый self-contained код для вставки в Tilda

## Как вставить в Tilda

1. Откройте файл `tilda_embed.html`
2. Скопируйте всё содержимое целиком
3. В Tilda добавьте блок `T123` или другой HTML-блок
4. Вставьте код в блок без изменений
5. Опубликуйте страницу
