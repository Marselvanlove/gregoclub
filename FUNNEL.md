## ⏰ Расписание scheduler

| Задача | Интервал | Описание |
|--------|----------|----------|
| `check_expired_subscriptions` | Ежедневно в 09:00 (Madrid) | Проверяет истёкшие подписки, исключает из канала |
| `send_pending_reminders` | Каждые 10 минут | Отправляет напоминания pending пользователям |
| `send_expiry_warnings` | Каждые 6 часов | Предупреждает об автопродлении (за 3 дня) |
| `sync_google_sheets` | Каждый час | Синхронизирует данные с Google Sheets |

## 🚀 Как редактировать тексты

1. Открой файл `bot/texts.py`
2. Найди нужную переменную (например, `NEW_WELCOME`)
3. Измени текст
4. Перезапусти бота: `docker-compose down && docker-compose up -d --build`

## 📸 Фото воронки

| Переменная окружения | Описание | Где используется |
|--------------------------|-------------|-------------------|
| `WELCOME_PHOTO_ID` | Главное фото GREGO CLUB | Приветствие `/start` |
| `INCLUDES_PHOTO_1_ID` | Спикинги + База знаний | Кнопка "Узнать больше" |
| `INCLUDES_PHOTO_2_ID` | Встречи + ИИ-ассистент | Кнопка "Узнать больше" (второе фото) |
| `PRICES_PHOTO_ID` | Фото с ценами | Тарифы `/pay` |

### Как загрузить фото

1. Отправьте фото боту в любом чате
2. В логах найдите `file_id` фото
3. Добавьте `file_id` в `.env` файл

```bash
# Пример .env
WELCOME_PHOTO_ID=AgACAgIAAxkBAAI...
INCLUDES_PHOTO_1_ID=AgACAgIAAxkBAAI...
INCLUDES_PHOTO_2_ID=AgACAgIAAxkBAAI...
PRICES_PHOTO_ID=AgACAgIAAxkBAAI...
```
