# Инструкция по деплою бота

## Автоматическое создание таблиц

**Важно:** Миграции БД выполняются автоматически при старте контейнера. Вам НЕ нужно запускать SQL скрипты вручную.

### Как это работает

При запуске приложения функция `init_db()` в `@/Users/zho/CascadeProjects/windsurf-project/database/__init__.py:19-73`:

1. **Создает все таблицы** из моделей SQLAlchemy (`Base.metadata.create_all`)
2. **Автоматически добавляет новые колонки**, если их нет:
   - `users.last_pay_click_at`
   - `users.pending_reminder_step`
   - `users.expiry_warning_sent_at`
   - `users.last_purchase_at` ✓ (для проверки входа в группу)
   - `users.group_join_check_sent` ✓ (флаг отправки проверки)
   - `scheduled_broadcasts.zoom_link`
   - `scheduled_broadcasts.reminder_15min_sent`
   - `scheduled_broadcasts.reminder_5min_sent`

### Деплой в Docker

```bash
# 1. Соберите контейнер
docker-compose build

# 2. Запустите
docker-compose up -d

# 3. Проверьте логи
docker-compose logs -f bot
```

**Готово!** Все таблицы и колонки создадутся автоматически.

### Что происходит при первом запуске

```
[INFO] Инициализация базы данных...
[INFO] База данных инициализирована.
```

Если таблиц не было - они создаются.  
Если не хватало колонок - они добавляются автоматически.

### Что происходит при обновлении

При пулле новой версии кода с новыми полями в моделях:

```bash
# Просто перезапустите контейнер
docker-compose restart bot
```

Новые колонки добавятся автоматически при старте.

### Бэкап данных

База данных SQLite хранится в `./data/bot.db` (примонтирована как volume).

Для бэкапа:
```bash
cp ./data/bot.db ./data/bot.db.backup
```

### Проверка структуры БД

```bash
# Войдите в контейнер
docker-compose exec bot bash

# Откройте SQLite
sqlite3 /app/data/bot.db

# Посмотрите структуру таблицы users
.schema users
```

Вы должны увидеть все поля, включая `last_purchase_at` и `group_join_check_sent`.

## Новые фичи в этом релизе

### Проверка входа в группу после покупки

**Автоматически работает после деплоя:**

1. Пользователь покупает подписку
2. Получает сообщение с предупреждением, что ссылка одноразовая и действует 24 часа
3. **Через 5 минут** получает вопрос "Вы зашли в группу?"
4. Отвечает кнопками Да/Нет

**Настройка не требуется** - все работает из коробки.

### Планировщик

Задача `send_group_join_check` запускается каждую минуту и проверяет пользователей, которым нужно отправить уведомление.

Логи:
```bash
docker-compose logs -f bot | grep "Проверка входа в группу"
```
